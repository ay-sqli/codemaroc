# 🔧 العناصر الميكانيكية المرتبطة بسلامة السياقة (Éléments Mécaniques)

## 📌 1. تعاريف (Définitions)
- **تجهيزات المركبة**: لسلامة السائق (وسادات هوائية...) والآخرين (ضبط الأضواء) والراحة والسهولة
- **السلسلة الحركية**: المحرك ← الواصل ← علبة السرعة ← العجلات (دائما بهذا الترتيب)
- **المذكرة الوصفية**: الوصف الكامل للمركبة (ضغط الإطارات، سعة الخزان...)
- **دليل الصيانة**: يُقرأ عند تسلم المركبة (الخصائص ودورية الصيانة)
- **مستويات السوائل**: الزيت، سائل التبريد، سائل الفرامل، غسل الزجاج...
- **ضغط الإطارات**: التحام أمثل مع الأرض + خطر انفجار أقل

## 🚗 2. المكونات (Composants)
- {img:1683197885750.png} **الهيكل: بنية تحمل الأجزاء المحركة**
- {img:1683017253665.jpeg} **المحرك: يحول الطاقة الحرارية (احتراق الوقود) إلى طاقة حركية**
- العجلات الأمامية ← مرتبطة بالمقود (العجلات الموجهة)
- العجلات الخلفية ← تتبع الأمامية
- {img:1683017253705.png} **المقود: التحكم في العجلات الأمامية ومسار المركبة**

## 🛞 3. الإطارات (Pneus)
- {img:1693319605704.png|big} أنواع الإطارات
- العجلة = الطوق + الإطار المطاطي
- {img:D%C3%A9signation%20sur%20pneus%20compress%C3%A9.png|big} المعلومات المنقوشة على الإطار
- Run Flat ← تواصل السير بعد الثقب: ≤ 80 كلم/س لمسافة قد تصل 250 كلم
- Tubeless ← بدون أنبوب داخلي، الصمام على الطوق

## ⚙️ 4. علبة السرعة (Boîte de vitesses)
- المستوى 1 ← أكبر عزم: الإقلاع والعقبات الحادة جدا
- المستوى 2 ← عزم جيد: العقبات
- المستوى 3 ← عزم وسرعة: العقبات والمنعرجات
- المستوى 4 ← الطرق المستوية
- المستوى 5 ← أكبر سرعة: الطرق المستوية بدون منعرجات
- ارفع المستوى فوق 2500 دورة/د، اخفضه تحت 1500 دورة/د
- {img:1685453370907.jpeg|big} مستويات السرعة
- اليدوية (BVM) ← صيانة أقل وأرخص، السياقة الاقتصادية، الأكثر انتشارا
- الأوتوماتيكية (BVA) ← راحة في الازدحام، اليدان على المقود، لكن استهلاك وثمن وصيانة أكثر

## 🦶 5. الدواسات (Pédales)
- يمين ← التسريع
- وسط (أو يسار في الأوتوماتيكية) ← الحصر
- يسار ← الواصل (فقط في اليدوية): الضغط = فصل المحرك عن العلبة
- {img:1685026788090.png} **مركبة بعلبة سرعة يدوية: 3 دواسات**
- {img:1685025480508.png} **مركبة بعلبة سرعة أوتوماتيكية: دواستان**

## 🅿️ 6. أوضاع العلبة الأوتوماتيكية (P R N D)
- {img:1685114219327.png} **P موقف، R رجوع، N حياد، D سير للأمام**
- P ← عند التوقف: يمنع نقل الحركة (حصار ثان)
- R ← الرجوع إلى الخلف
- N ← المحرك يدور بحرية دون تحريك العجلات
- D ← السير للأمام مع تغيير تلقائي للمستويات

## 📟 7. لوحة القيادة (Tableau de bord)
- {img:1683017253749.jpeg|big} لوحة القيادة
- عداد الدورات ← دورات المحرك في الدقيقة
- عداد السرعة ← كلم/س
- مؤشر الوقود ← يسار فارغ، يمين ممتلئ
- حرارة سائل التبريد ← تستقر عند 90°م
- أسباب ارتفاع الحرارة: تسرب السائل، مضخة الماء، المبرد، حشية رأس الأسطوانة، المستشعر
- {img:1683017253818.png} **مؤشرات التنبيه الحمراء: عطب خطير ← توقف فورا**
- ألوان المؤشرات
  - 🔴 أحمر ← خطر فوري: توقف
  - 🟠 برتقالي ← خطر محتمل: عطل أو مراقبة
  - 🟢🔵 أخضر وأزرق ← تجهيزات تعمل (الأضواء، المثبت...)
- {img:1685455373856.png|big} مؤشرات لوحة القيادة

## 🔩 8. المحرك ومبدأ الاشتغال (Moteur)
- {img:1686924689727.jpeg|big} المكونات الأساسية للمحرك
- محرك بنزين ← اشتعال بالشرارة (الشماعات)
- محرك غازوال ← اشتعال بالانضغاط
- رباعي الأشواط: السحب ← الانضغاط ← الشغل ← العادم
- {img:1689597879752.png|big} السلسلة الحركية للمحرك
- المولد يعيد شحن البطارية عند دوران المحرك

## 🎛️ 9. وسائل التحكم (Commandes)
- {img:1683122836359.png} **وسائل التحكم حول المقود: الأضواء، المؤشرات، المساحات**
- ذراع المؤشرات على اليسار ← تحت = يسار، فوق = يمين
- ذراع المساحات على اليمين ← درجات للسرعة
- {img:1683017254224.jpeg} **التهوية: الشدة، الحرارة (أزرق بارد/أحمر ساخن)، تدوير الهواء، المكيف، إزالة الضباب**
- {img:1683274038166.png} **واقية الشمس**
- أحزمة السلامة + مقاعد الأطفال (في المقاعد الخلفية)

## 💡 نصائح المدرب (Astuces du moniteur)
- ألوان المؤشرات مثل الأضواء: أحمر قف، برتقالي انتبه، أخضر يعمل
- 1500 ↓ / 2500 ↑ : قاعدة تغيير السرعة
- الحرارة فوق 90° وترتفع ← توقف قبل إتلاف المحرك
- الترتيب: محرك ← واصل ← علبة ← عجلات

## ⚠️ فخاخ الامتحان (Pièges d'examen)
- المؤشر الأحمر ← توقف فورا وليس «عند أقرب مرأب»
- الأوتوماتيكية: لا دواسة للواصل
- الوضع P ليس بديلا كاملا عن الحصار اليدوي
- Run Flat لا تتجاوز 80 كلم/س بعد الثقب
